# إضافة Mina Christmas Desktop للمتصفح — v1.1.0

هذه إضافة مستقلة لـ Google Chrome وMicrosoft Edge. تعمل داخل صفحات الويب العادية (HTTP/HTTPS)، بينما تبقى مؤثرات برنامج Windows على سطح المكتب فقط.

## التثبيت

1. نزّل مستودع MinaChristmasDesktop وافتح مجلد المشروع.
2. افتح Chrome واكتب `chrome://extensions`، أو Edge واكتب `edge://extensions`.
3. فعّل **Developer mode / وضع المطوّر**.
4. اضغط **Load unpacked / تحميل إضافة غير مضغوطة**.
5. اختر مجلد `browser_extension` الموجود داخل المشروع.
6. ثبّت الإضافة في شريط المتصفح للوصول إلى لوحة التحكم.

## المؤثرات

- ثلج خفيف متساقط داخل مساحة صفحة الويب.
- طبقة صقيع/ثلج زخرفية رقيقة على أطراف الصفحة.
- مرور زحافة بابا نويل على فترات.
- رجل ثلج صغير يتفاعل بحركة عند اقتراب المؤشر منه.
- مؤشر ماوس بطابع كريسماس.
- أصوات اختيارية للنقر والكتابة والحذف، مع مستوى صوت.

## الحفاظ على تجربة التصفح

- طبقة الرسوم تستخدم `pointer-events: none`؛ لذلك لا تحجب الأزرار أو الروابط أو مربعات الكتابة أو التمرير.
- لا نمنع أحداث لوحة المفاتيح ولا نقرأ محتوى حقول الإدخال أو نحفظ النص المكتوب. نستخدم رمز المفتاح فقط لتمييز Delete/Backspace عن ضغطات الكتابة.
- تختفي الرسوم عندما تكون الصفحة غير مرئية أو عند دخول وضع ملء الشاشة، لتجنب إزعاج الفيديوهات.
- لا تعمل الإضافة على صفحات المتصفح الداخلية مثل `chrome://` أو `edge://` أو متجر الإضافات. كما أن شريط العنوان والتبويبات خارج مساحة الصفحة، ولا تسمح إضافات الصفحات بتعديلهما.
- يمكن إيقاف أي مؤثر من لوحة الإضافة في أي وقت.

## ملاحظة

ملفات الإضافة موجودة في مجلد `browser_extension`. لا تحتاج مكتبات أو خادمًا أو اتصالًا خارجيًا، والإعدادات تُحفظ محليًا في مساحة مزامنة المتصفح.
